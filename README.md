# ConStyx

**ConStyx (Construct + Styx): named after the Greek river that marks the boundary between worlds, representing the connection point between reality and the Construct. This is a focus terminal disguised as a digital rain cascade.**


Seven programs run on the console: **Operator** (spot anomalies in the rain), **The Construct** (real training lessons), **Locations** (explorable 3D scenes), **Focus Mode** (ambient scenes for long work sessions), **Screensaver** (export your own rain), **ASCII Composer**, and **Code Vision** (your webcam as falling code, processed locally).

Free, with no accounts, no memberships, and no ads.
